# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | ✅ Yes             |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability in NetContext.ai, please report it responsibly by opening a [GitHub Security Advisory](https://github.com/dhruvv224/NetContext.ai/security/advisories/new) or contacting the maintainers directly through the repository's contact information.

When reporting a vulnerability, please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or proof-of-concept code.
- Any suggested mitigations or fixes.

You can expect:

- **Acknowledgement** within 72 hours of your report.
- **Updates** on the status of the issue as it is investigated.
- **Credit** in the fix release notes (if you wish).

We are committed to working with security researchers to resolve vulnerabilities responsibly.
