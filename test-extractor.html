How the Extractor & SKU Image ZIP Builder Work

1. Recursive Traversal

The extractor walks through the entire JSON structure recursively, checking every object and array at every depth level.

2. Detection & Deduplication

When it finds an object with a "cart_item" key (or a top-level array of extracted product objects), it deduplicates by product_id and preserves the complete object.

3. Snap-Door Bulk Image ZIP Format

Snap-Door's POST /api/v1/admin/inventory/images/bulk-zip endpoint expects a single .zip archive where each product has its own folder named after its uppercase SKU (product_id):

sku-images.zip
├── 396515/
│   └── main.png
├── 314/
│   └── main.png
└── 283/
    └── main.png
